# JobConnect – Full Stack Job Portal

BCA Full Stack Development-I academic project.

## Stack
Frontend: React, Vite, React Router, Axios, Context API
Backend: Node.js, Express, MongoDB, Mongoose
Auth: JWT + bcrypt

## Features
- Job seeker and employer registration/login
- Browse, search and filter jobs
- Job details and applications
- Employer dashboard
- Post/edit/delete jobs
- View applicants and update application status
- MongoDB persistence
- REST APIs

## Run Backend
cd backend
npm install
copy .env.example .env
npm run dev

## Run Frontend
cd frontend
npm install
npm run dev

Set MONGO_URI and JWT_SECRET in backend/.env.
